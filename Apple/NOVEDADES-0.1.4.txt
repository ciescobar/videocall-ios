MI-DRIVER APPLE 0.1.4 · BUILD 5 · 14/11/2026

VOLVER A MATRICULAR
Nuevo botón en la pantalla de dispositivos, junto a USER TEST, disponible
después de identificarse y cuando no hay llamada ni otra captura abierta.
Permite repetir las cinco posiciones en este orden exacto:
FRONTAL → ARRIBA → ABAJO → IZQUIERDA → DERECHA.
Ese mismo orden se aplica a la primera matrícula, tanto en Apple como Android.

El nombre actual se muestra sin permitir modificarlo en este flujo. Se pide
consentimiento para repetir la captura. La primera foto se compara con el
perfil anterior para comprobar que sea el usuario registrado. Las restantes
se comparan con la nueva frontal para conservar coherencia entre muestras.
Los umbrales, modelo SFace y condiciones cómodas de captura se mantienen.

El perfil anterior no se borra al iniciar ni durante las capturas parciales.
El reemplazo cifrado es atómico después de completar las cinco posiciones,
con una comprobación final de que la sesión siga activa. Cancelar o salir
antes del guardado invalida el resultado pendiente y conserva el perfil.
La comprobación abreviada al ingresar y USER TEST siguen siendo independientes.
